# Aihana Dalamud Plugins

FF14 Dalamud 插件仓库，提供 **Samurai PvP · 斩铁剑助手**、**Aihana PVP · 职业辅助与雷达**，以及 **CleaveCompass 群攻罗盘**、**Aihana Tuner 战斗调节器**测试版（API 15）。新增两款均为**测试版，未实测，可能崩溃**。

## 安装

在游戏中打开 **Dalamud 设置 → 实验性 → 自定义插件仓库**，添加并启用以下地址，然后保存：

```text
https://raw.githubusercontent.com/A1hana/DalamudPlugins/main/pluginmaster.json
```

在插件安装器中刷新列表，搜索 **Samurai PvP** 或 **Aihana PVP** 并安装。后续更新通过同一插件源获取。

## 职业辅助与雷达整合版

**Aihana PVP · 职业辅助与雷达** 把忍者 PvP 的低血量目标选择、星遁天诛热栏防误触、三印按钮调整及移动设置，与完整战场雷达合并到一个插件。雷达保留地图与 3D 绘制、玩家列表、标记、关注列表、连线及目标信息增强。

1.1.0.0 新增暗黑骑士夜昏方向辅助：手动释放时，按自身前后各 15 米、总宽 6 米计算覆盖敌人最多的方向，并取消当前目标、调整面向。可在设置的“暗黑骑士”页开关。忍者自动选中仅对当前职业为忍者的角色生效。

1.1.0.1 修复插件加载时因忍者热栏函数地址被重复解析而发生的崩溃，同时修复移动模块的同类地址错误。

1.1.0.2 更新移速字段识别，增加应用状态、重新应用按钮、写入回读和失败回退。角色就绪后会自动应用已保存倍率；恢复默认或卸载时还原修改前的速度。


通过上面的自定义插件仓库链接，直接在游戏内搜索 **Aihana PVP** 安装。插件列表会从本仓库的版本化安装包获取文件，安装和更新均在游戏内完成。已通过本地 API 15 编译、配置迁移与安装包校验；游戏内效果尚未验证。组件来源与许可声明见安装包内的 `THIRD_PARTY.txt`。

## 斩铁剑助手

- LB 就绪时，连续选择 5 米范围内预计斩杀人数最多的崩破目标。
- 过滤无敌、不死、受保护、兵器以及血量加护盾超过斩杀线的目标。
- 提供斩铁剑防误触和预计斩杀人数显示。
- 仅武士 PvP 生效，LB 由你手动释放。

输入 `/samlb` 打开设置；`/samlb on`、`/samlb off` 开关插件，`/samlb hud` 切换人数显示。

人数根据客户端状态估算，实际结果可能受延迟、移动、回血和护盾变化影响。

## 魔光键影助手个人环境兼容版

**仅为个人配置环境兼容版。** `KeyboundBrawlerLocal 0.1.0.13` 基于 [NiGuangOwO 的 KeyboundBrawler 0.1.0.12](https://github.com/NiGuangOwO/DalamudPlugins/tree/b0f5161e2790616cc18e291aa288470953897e33/plugins/KeyboundBrawler)，适配个人使用的国服客户端 `2026.10.06.0000.0000`、Dalamud `26-10-21-01 / API 15` 环境，不代表原作者官方更新或其他配置环境的兼容承诺。

保留上游新版功能：固定或按词条长度计算提交间隔、延迟抖动、在悬浮窗调整延迟，以及成绩窗口自动点击退出。首次可输入时立即提交，延迟只作用于两次提交之间。结算退出可以在设置中关闭。

个人兼容修复继续保留：通过 Dalamud 接口识别被替换的原始虚函数表；阶段界面暂时隐藏时暂停输入，窗口稳定 250ms 后重新校验；窗口重建后恢复，保留手动暂停和累计提交次数，并补充具体失败日志。保留上游新增的写入前虚函数表复核与结算事件校验。

**已取消 500 毫秒最低输入间隔。** 固定间隔与动态计算结果均允许 `0–30000ms`。设为 0 表示不额外等待，实际提交仍受游戏帧更新、输入框可用状态及目标校验约束。动态模式仍会追加“字符数 × 每字延迟 + 抖动”；如需不追加延迟，关闭动态模式并将基础间隔设为 0，或将基础间隔、每字追加和抖动全部设为 0。界面稳定检查不属于输入间隔。

已完成编译（0 警告、0 错误）和 84 项离线检查，覆盖低于 500ms 的固定及动态延迟、Unicode 字符计数、配置读取、阶段恢复、虚函数表校验，以及同一成绩窗口只发送一次退出点击。该版本的实际游戏效果仍待验证。
